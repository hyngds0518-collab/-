# 회의록 분석 대시보드

회의록 PDF를 구조화·분석해 **결정·실행·성과·리스크**를 시각적으로 보여주는 HTML 대시보드입니다.
기본 데이터는 `data/MOMENTLAB_회의록_20건.pdf`(MOMENT LAB 신제품 런칭 프로젝트, 회의 20건)입니다.

## 실행

- `index.html`을 브라우저로 열기 (또는 단일 파일 `dist/meeting-dashboard.html`)
- 인터넷 연결 필요: 차트(ECharts)와 PDF 업로드(pdf.js)를 CDN에서 불러옵니다.

## 구성 (12개 탭)

| 탭 | 내용 |
|---|---|
| 개요 | 11개 영역을 항목별 그래프 한 장씩으로 요약 (카드를 누르면 해당 탭으로 이동) |
| 01 회의 기본정보 | 회의 성격·유형·장소, 부서/참석자 × 회의 매트릭스, 회의 목록 |
| 02 프로젝트 흐름 | 9단계 타임라인 (● 정기 ▲ 임시 ⚠ 긴급), 단계별 요약 |
| 03 안건·논의 | 주제 비중, 단계별 주제 변화, 키워드, 부서 간 이견 지도, 반복 이슈 |
| 04 의사결정 | 확정/조건부/잠정/보류, 승인 레벨, 결정 변경 흐름(구체화·유지·연기·번복) |
| 05 실행 관리 | Action Item 간트, 후속 회의 기록 기반 최종 상태·지연 추적 |
| 06 성과 추적 | 이전 회의 목표 → 현재 결과 (Closed Loop), 지표별 달성률, 소재·프로모션 비교 |
| 07 KPI 성과 | KPI별 목표 대비 실제, 이전 대비, 상태(달성/주의/미달), 시점별 추이 |
| 08 위기·리스크 | 발생 → 대응 → 해결 → 예방 흐름, 미결 이슈 라이프사이클 |
| 09 부서 분석 | 협업 네트워크, 부서별 참여·업무·완료율, 부서 × 주제 |
| 10 AI 인사이트 | 반복 문제·의사결정 패턴·성과 학습·병목·리스크 신호 (근거 ID 포함) |
| 11 차년도 기획 | 올해 문제 → 학습 → 2027 반영, 전략 매트릭스, 차년도 KPI, 리스크, KPT |

상단 **필터 바**(기간·성격·유형·단계·부서·참석자·회의·키워드)는 모든 탭에 동시에 적용됩니다.

## 회의록 업로드

**회의록 업로드** 버튼으로 표준 양식(기본정보 + 01~08 섹션)의 PDF나 내보낸 JSON을 추가할 수 있습니다.
파일은 브라우저 안에서만 처리되며(pdf.js → `assets/js/parser.js`), 업로드 데이터는 이 브라우저의 localStorage에 보관됩니다.

## 데이터 구분

- **원문 추출**: 회의록에서 직접 추출·집계한 값
- **AI 분석**: 원문을 근거로 해석·정규화한 값 (`assets/data/ai-annotations.js`, 기본 데이터셋 전용). 업로드 데이터에는 규칙 기반 자동 분석이 적용됩니다.

## 파일

```
index.html                     대시보드
assets/js/parser.js            PDF → 구조화 JSON (위치 기반 표 파서, 브라우저/Node 공용)
assets/js/analytics.js         분류·집계·추적 로직
assets/js/views.js, app.js     화면 / 필터·업로드·드로어
assets/data/base-data.js       기본 회의록 추출 결과 (자동 생성)
assets/data/ai-annotations.js  AI 분석 레이어
scripts/build-data.mjs         PDF → base-data.js  (npm i pdfjs-dist 후 실행)
scripts/build-dashboard.mjs    단일 HTML 빌드 → dist/
```
